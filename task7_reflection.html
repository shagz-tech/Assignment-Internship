Task 7: Reflection & Learning

During Week 1, I learned the fundamentals of HTML, including how a webpage is structured using tags like <html>, <head>, and <body>. I explored text formatting elements such as headings, paragraphs, bold, italic, underline, and superscript/subscript. I also learned how to add hyperlinks, images, ordered and unordered lists, nested lists, and tables to organize content effectively.

The most challenging part was understanding how to properly structure HTML forms with different input types like radio buttons, checkboxes, and dropdown menus, since getting the labels and grouping correct required careful attention.

I enjoyed learning semantic HTML the most, as tags like <header>, <nav>, <main>, <section>, <article>, and <footer> make the code more meaningful and easier to read, rather than just using generic <div> tags everywhere.

Overall, this week gave me a strong foundation in HTML, which is the building block of every website. Understanding HTML clearly will help me move forward confidently into CSS and JavaScript, since a well-structured HTML page makes styling and adding interactivity much easier in the coming weeks of web development.
