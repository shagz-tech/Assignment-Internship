# 🌐 HTML Fundamentals — Week 1 Assignment

> Internship Program | Web Development Track

A collection of HTML5 pages demonstrating core web development fundamentals — 
from document structure to semantic HTML — built as part of the Week 1 
internship assignment.

---

## 🎯 Objective

To understand the fundamentals of HTML by learning how web pages are 
structured, how different HTML elements are used, and how to build a 
simple static website using semantic HTML and forms.

## ✅ What's Covered

- **Document Structure** — DOCTYPE, `<html>`, `<head>`, `<body>`, meta charset & viewport
- **Text Formatting** — Headings, paragraphs, bold/italic/underline, line breaks, sup/sub, comments
- **Links, Images, Lists & Tables** — Internal/external links, alt-text images, ordered/unordered/nested lists, tables
- **HTML Forms** — Student Registration Form with text, email, radio, checkbox, dropdown, date, submit/reset
- **Semantic HTML** — `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
- **Mini Project** — Combines all above concepts into one cohesive page
- **Reflection** — Personal learning summary
